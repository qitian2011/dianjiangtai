点将台 · 微信小程序（控制端完整版）导入与联调步骤
================================================

这是用小程序原生语言（WXML/WXSS/JS）对网页控制端（ctrl.html）的完整重写，
不是 web-view 套壳。功能对照网页版五大区块，桌面专属项（开机自启/主题/AI语音引擎）不迁移。

--------

├─ app.js / app.json / app.wxss        入口；app.json 定义底部 5 个功能页（tabBar）
├─ config.js                           云开发环境 ID 配置（唯一要手改的）
├─ project.config.json                 AppID 已填：wx675c232206b52f17

└─ pages/connect   连接与班级：云端访问密码(PIN)设置 · 班级解锁 · 班级切换（点任何页顶部「⚙ 连接」进入；PIN 失效自动弹出）

一、导入项目（约 2 分钟）
1. 打开微信开发者工具 → 「导入项目」→ 目录选本文件夹
2. AppID 自动读取 wx675c232206b52f17（用正式注册号，测试号无法用云开发）
3. 首次使用扫码登录：请扫「注册该小程序的管理员微信」

二、开通云开发（必做，约 3 分钟）
1. 工具栏点「云开发」→ 开通 → 创建环境（开发期免费，个人账号可用）
2. 创建后复制【环境 ID】（形如 dianjiangtai-xxx-1gxxxxxx）
3. 打开根目录 config.js，把 CLOUD_ENV 改成你的环境 ID 并保存（只有一个环境时可留空）

三、部署云函数 proxy（必做，约 2 分钟）
1. 左侧资源管理器展开 cloudfunctions → 右键 proxy → 「上传并部署：云端安装依赖」
2. 等待完成（首次 30-60 秒）
3. 如线上 worker 域名有变化：云开发控制台 → 云函数 → proxy → 配置 → 环境变量
   新增 BASE_URL = https://你的域名（默认 dianjiangtai.18117041808.workers.dev）

四、编译联调（重点看这里）
1. 点「编译」→ 默认进入「点名」页。首次使用若云端未连通，页面中央会出现
   【⚠ 连接云端失败】红字卡片（不再是空白页），按卡片提示处理：
   · 提示「云端访问密码不正确或未设置」→ 点卡上「⚙ 连接设置」→ 输入【云端访问密码】
     （当前为 20260901，服务器全局口令，不是班级密码）→ 「保存密码并连接」
   · 提示「云函数调用失败」→ 回到第二、三步：开通云开发 + proxy 上传部署 + config.js 填 CLOUD_ENV
   · 提示「云端未配置访问密码（PIN）」→ 云端 worker 未注入 PIN secret，属云端侧问题
2. 连接成功后任意页面顶部都有一条班级栏：示例班（默认，无锁，直接可用）+ 全部班级；
   点班级即切换；带「锁」的班级点击后弹窗输【班级访问密码】（该班自行设置）
3. 逐页验收：
   · 点名页：点「🎲随机点名」→ 服务端动画 3 秒 → 显示结果 → 请回答(选倒计时)/跳过/标记对错
   · 传呼页：选人 → 去处 → 发送 → 大屏弹窗 5 秒；当前传呼可「已到/撤回」
   · 名单页：导入文本一行一名（姓名,学号,组别,权重）创建新班 → 可切过去用
   · 课表页：填一周课程与每节时间 → 大屏课表同步显示；公告/备忘也按班级保存
   · 设置页：班级密码、动画时长、音量等与大屏实时联动
4. 实时性说明：小程序端没有 SSE，各页每 3~5 秒轮询快照（点名后为取结果会高频轮询
   至动画结束）；控制端操作到大屏展示延迟 ≤ 1 轮询周期 + 动画时长，课堂无感

五、真机体验
- 工具栏「预览」→ 手机微信扫码（管理员或已添加的体验成员）
- 或「上传」→ mp.weixin.qq.com 版本管理 → 选为体验版 → 体验成员扫体验码

两套密码说明（别再混淆）
------------------------
· 云端访问密码 PIN：服务器全局口令，全班共用，仅首次/失效时输入（部署端 secret 设置）
· 班级访问密码：某个班级自己加的锁，进该班、改名单、删除该班时才需要；每班可不同
· 示例班默认无锁；正常上课场景几乎不会看到第二个密码框

常见问题
--------
· 云函数调用报 -501000 / env 错：config.js 的 CLOUD_ENV 没填或填错
· 提示「云端未配置访问密码」= HTTP 503：worker 未注入 PIN（fail-closed）
· 提示「云端访问密码不正确」= HTTP 401：PIN 输错或云端 secret 已被轮换
· 输入班级密码总失败：确认输的是「班级访问密码」而不是云端 PIN；错 5 次锁 30 秒
· 点班级没反应：先确认 PIN 已保存连接成功（顶部班级栏应显示示例班且带当前高亮）
