# 点将台 · 课堂互动大屏系统

> 教室一体机 + 教师手机，零依赖的课堂互动点名系统。Node.js 实现，无需 npm install，U 盘拷贝即可运行。
> 另提供 Cloudflare Workers 云端版，手机在**任何地方**都能打开，不依赖教室局域网。

## 这是什么

一套部署在教室一体机（Windows）上的课堂互动工具：

- **大屏展示端**（screen.html）：一体机浏览器全屏显示，负责点名动画、倒计时、传呼卡片
- **教师控制端**（ctrl.html）：教师手机连接教室同一 WiFi 后打开，负责点名、传呼、名单管理

两端通过 SSE 长连接 + POST 指令实时通信，局域网延迟 <200ms。

## 快速开始

1. 一体机安装 [Node.js](https://nodejs.org/)（任意版本，无需任何 npm 包）
2. 双击 **`app/启动.bat`** → 自动启动服务并打开大屏页（浏览器按 F11 全屏）
3. 手机连教室同一 WiFi，浏览器打开大屏待机页底部显示的地址（`http://一体机IP:8080/ctrl.html`）
4. 开始使用：点名页点「随机点名」→ 大屏动画定格 → 「请回答」计时 → 标记答对/答错/未答

> 局域网连不上？双击 `app/放行防火墙.bat`（需管理员）放行 8080 端口。
> 远程访问（在家/办公室管理名单）？见 `app/Tailscale远程连接指南.md`。

### 云端部署（Cloudflare Workers，免费）

想让手机在**任何地方**（不连教室 WiFi）也能打开点名、管名单？用云端版：

1. 安装 [Wrangler](https://developers.cloudflare.com/workers/wrangler/)（Cloudflare 官方 CLI），登录你的 Cloudflare 账号
2. 在 `app/` 目录执行：`wrangler deploy`
3. 部署完成会得到 `https://dianjiangtai.<你的子域>.workers.dev` 地址，手机直接打开即可
4. （可选）绑定自定义域名：Cloudflare 后台 → Workers 和 Pages → dianjiangtai → 设置 → 域和路由 → 添加自定义域（如 `qitian.dpdns.org`）

> 细节：
> - 名单存在 Durable Object SQLite 存储，**重启不丢**；会话状态（本轮已点/答题/传呼）与本地版一致，DO 重启即清
> - 访问密码：`app/wrangler.jsonc` 里 `vars.PIN`，留空 = 不启用。**注意**：无密码时名单对学生可见、知道网址的人都能操作，建议填个数字密码再 deploy
> - 云端版时区已按东八区处理（课表节次、请假跨天），不会差 8 小时

## 技术要点

- **零依赖**：`server.js` 仅用 Node 内置模块（http/os/fs），不需要 `npm install`
- **实时通道**：SSE 下行 + POST 上行，浏览器断线自动重连
- **数据持久化**：全部在 `roster.json`，自动保存；删除即恢复示例数据
- **多网卡适配**：服务自动列出所有网卡的候选地址，插 USB 共享/开热点后地址自动新增
- **云端版架构**：Worker（路由 + 静态资产）+ Durable Object「Room」（教室状态 + SSE 广播 + 名单持久化），名单存 DO SQLite 重启不丢
- **学生字段**：`name` 姓名、`sid` 学号、`group` 组别、`weight` 权重（0=永不抽中）、答题统计、`absent` 当日请假
- **replaceRoster 命令**：可整体替换某班名单（保留班级设置如课表/公告，统计清零），适合学期初批量换名单
