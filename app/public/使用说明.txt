点将台桌面版 · 使用说明
================================

【这是什么】
一个"云端壳"程序：双击运行后，自动打开 Cloudflare 云端版点将台
（qitian.dpdns.org），无需安装任何服务、无需配置，教室电脑能上网就能用。

【用哪个文件】
推荐：启动点将台.bat（一键启动器，自动跑便携版，最稳）
推荐：点将台桌面版-单文件版-v6.exe（75MB，绿色单文件，拷U盘即用）✅ v1.1.2
  └ 运行时图标（任务栏/窗口/通知/托盘）= 「点」图标 ✅
  └ 资源管理器里 exe 文件图标 = 默认 stub（sfx 限制；想要此图标也换，见下文）
备选：点将台桌面版-便携版.zip（解压后双击 便携版\点将台桌面版.exe）
  └ 所有位置图标都是「点」图标（含资源管理器 exe 文件图标）✅
  └ 适合老师想看到"自己的图标"的场景
（v1.1.2 = 管理员权限版：双击会弹一次 UAC 提示，点【是】即开，
  从根上解决了"普通双击完全没反应、必须右键管理员才能开"的问题）

【首次运行会弹 UAC（重要）】
v1.1.2 起程序声明"需要管理员权限运行"，所以每次启动 Windows 都会弹
「用户账户控制」窗口——请点【是】。这是正常现象：
  · 只有这样才能绕开系统对普通权限程序的静默拦截（此前两版都打不开的根因）
  · 只连自家云端 https 页面（qitian.dpdns.org），不会改动系统，请放心
  · 若不想每次手点：开始菜单搜"更改用户账户控制设置"→ 拉到"从不通知"→ 确定
    （降低安全级别，仅建议在自己电脑/教室一体机上这么设）
  · 开机自启动也会触发 UAC 弹窗：如需"开机无人值守自动进大屏"，
    请先在设置里把 UAC 调到"从不通知"，再开启自启

【运行不了怎么办？（双击完全没反应）】
v1.1.1 曾尝试"禁用沙箱"修复，但你这台机器上仍复现；
v1.1.2 改为**程序请求管理员权限**（双击自动弹 UAC，点"是"即开）。
请先确认用的是 v6.exe / 新版便携 zip（v1.1.2），双击应看到 UAC 弹窗。
若双击后【连 UAC 弹窗都不出现】仍没反应，按顺序试：
  ① 双击本目录里的【启动点将台.bat】（自动清环境变量 + 跑便携版）✅推荐
  ② 把整个「点将台桌面版」文件夹加入 Windows 安全中心排除（见下）
  ③ 右键 exe →【以管理员身份运行】（若这能开而双击不弹 UAC，多半是
     Windows Defender 实时防护拦了未签名程序的自解压/提权，加排除即可）
原因说明：
  · 旧版双击没反应的两个常见元凶已修复/规避——
    ① 环境变量 ELECTRON_RUN_AS_NODE=1（开发工具/终端注入）：让程序以
       "纯 Node 模式"静默运行，不开窗口秒退。请在【资源管理器】里双击，
       不要从开发工具的文件面板双击；或用 启动点将台.bat。
    ② 系统对"普通权限运行的未签名 Electron"静默终止：
       v1.1.1 禁沙箱无效 → v1.1.2 改为请求管理员权限（UAC 提权后运行）
  · 若用 v6 仍无反应：可能是 Windows Defender 实时防护拦了未签名程序，
    加排除即可——开始菜单搜"病毒和威胁防护"→ 管理设置 →
    【排除项】→ 添加排除 → 文件夹 → 选「点将台桌面版」所在文件夹 → 确定

【清理旧版本（升级时）】
旧版 .exe 可能被 Windows 搜索索引锁住无法直接覆盖/删除：
1. 关掉资源管理器窗口（释放文件锁）
2. 右键旧版 .exe → 重命名成 _旧-xxx.exe（绕过锁）
3. 再右键删除

【首次运行提示（重要）】
因为是未签名程序，Windows 可能弹出蓝色提示
"Windows 已保护你的电脑 / 未知发布者"——
点【更多信息】→【仍要运行】即可（仅首次，属正常现象，非病毒）。

【功能一览】
· 系统托盘常驻：最小化后程序藏在托盘（右下角箭头里），不会退出
· 控制端窗口：自动加载云端教师控制端（发传呼、点名、看记录）
· Windows 原生通知：传呼/叫人时右下角弹系统通知
· 大屏端：托盘菜单 →【打开大屏端】，默认最大化窗口（非全屏，方便鼠标关闭）
· 大屏全屏的进入/退出方式（大屏机通常没键盘，以下都只需鼠标）：
  ① 右键大屏任意位置 → 菜单选【进入全屏 / 退出全屏】
  ② 大屏右下角 ⚙ 齿轮按钮 → 面板里有 退出全屏/刷新/关闭
  ③ 键盘 Esc 退出全屏、F11 切换全屏（有键盘时可用）
  ④ 系统托盘 →【大屏端：退出全屏】（全屏状态下会出现）
· 断网自动重试：连不上云端会弹提示并每 3 秒自动重试
· 开机自启（v1.1 新增）：两种方式——
  ① 控制端窗口 →【设置】标签 →「💻 本机桌面版 · 开机自启动」：
     勾选开关，并选择开机后进入【控制端】还是【大屏端】。
     大屏端模式适合教室一体机：开机直接进大屏展示，控制端收进托盘待命。
  ② 系统托盘右键 → 勾选【开机自动启动】（快速开关；启动界面跟随设置页选择）
· 浏览器打开云端：托盘菜单可随时在默认浏览器打开云端网址

【常见问题】
· 白屏/打不开：检查网络能否访问 qitian.dpdns.org（断网或学校防火墙拦截）
· 通知不弹：检查 Windows 设置→系统→通知 里是否允许本应用通知
· 单文件版资源管理器文件图标仍是默认（stub 限制）：
  想换成「点」图标 → 在你电脑上开「设置→系统→开发者选项→开发人员模式」，
  然后告诉开发者（我）重新打一次带完整图标的单文件版（需符号链接权限）。
  或改用便携版.zip（文件图标已是"点"）。
· 更新：直接把新版 exe 替换旧文件即可（班级数据在云端，不丢失）

【手机/平板端】
老师手机浏览器直接打开 https://qitian.dpdns.org/ctrl.html 即可控制，
与桌面版数据实时同步。
