点将台桌面版 · 使用说明 v2.0.0
================================

【v2.0.0 重大变更：拆分为两个独立 App】
  v1.x 是一个 exe 双模式（控制端 + 大屏端共存）。v2.0.0 起拆为两个独立 App：
    · 点将台-控制端：教师控制窗口（班级/点名/传呼/设置/开机自启）
    · 点将台-大屏端：教室大屏展示（接收传呼/系统通知+任务栏闪/AI 播报）
  两端通过云端 worker.js 通信（与你之前的部署完全兼容，云端零改动）。
  下载页 qitian.dpdns.org/download 现在有 4 张卡片，请按需下载。

【这是什么】
两个"云端壳"程序：双击运行后，自动打开 Cloudflare 云端版点将台
（qitian.dpdns.org），无需安装任何服务、无需配置，教室电脑能上网就能用。

【用哪个文件（按你的角色）】
教师（用「控制端」）：
  推荐：点将台-控制端-便携版.zip（约 103 MB）
       解压后双击「点将台-控制端.exe」即可，所有图标均为「点」图标。
  也可：点将台-控制端.exe（约 71 MB，单文件版）

教室大屏（用「大屏端」，建议装在一体机/教室电脑）：
  推荐：点将台-大屏端-便携版.zip（约 103 MB）
       解压后双击「点将台-大屏端.exe」即可。
  也可：点将台-大屏端.exe（约 71 MB，单文件版）

  运行时图标（任务栏/窗口/通知/托盘）= 「点」图标 ✅
  资源管理器里 exe 文件图标 = 默认 stub（单文件版限制；想要「点」图标也换，请用便携版）

【首次运行会弹 UAC（重要）】
v1.1.2 起所有版本程序都声明「需要管理员权限运行」，所以每次启动 Windows
都会弹「用户账户控制」窗口——请点【是】。这是正常现象：
  · 只有这样才能绕开系统对普通权限程序的静默拦截（v1.1.1 之前双击没反应的根因）
  · 只连自家云端 https 页面（qitian.dpdns.org），不会改动系统，请放心
  · 若不想每次手点：开始菜单搜「更改用户账户控制设置」→ 拉到「从不通知」→ 确定
    （降低安全级别，仅建议在自己电脑/教室一体机上这么设）
  · 开机自启动也会触发 UAC 弹窗：如需「开机无人值守自动进大屏」，
    请先在设置里把 UAC 调到「从不通知」，再开启自启

【两端联动 / 大屏端退到托盘后还能收到通知（关键）】
两端都装好后：
  1. 教师在「控制端」发起传呼 → 云端 cmd API → SSE 广播
  2. 「大屏端」SSE 实时收到事件 → 前端调 window.djt.notify(标题, 内容)
  3. Windows 系统通知立即弹出（右下角 toast），即使大屏窗口已退到托盘也不会漏看
  4. 同时大屏端主进程调 BrowserWindow.flashFrame(true) 闪烁任务栏
  5. 大屏前端弹出传呼大弹窗（5 秒自动收起）+ AI 语音播报

  即：大屏端"× 按钮"≠ 退出程序，而是「退到托盘保 SSE 监听」；
  控制端的传呼永远会通过 Windows 系统通知提醒，不会因为大屏被遮挡/最小化而漏掉。

【控制端特有功能】
  · 班级管理、点名、传呼、统计
  · 「本机桌面版」设置卡片：开关开机自启、可选启动界面（控制端/大屏端）
  · 系统托盘：显示/隐藏控制端、发送测试通知、退出

【大屏端特有功能】
  · 教室大屏展示（最大化）
  · F11 切换全屏、Esc 退出全屏（仅全屏时生效）
  · 任意位置右键菜单：进入/退出全屏、刷新、关闭
  · 右下角悬浮 ⚙ 齿轮面板（无键盘/触摸屏场景兜底）：退出全屏/刷新/关闭
  · 系统托盘：显示/隐藏大屏、发送测试通知、退出

【运行不了怎么办（按顺序试）】
  ① 双击 exe → 应弹 UAC → 点【是】→ 启动
  ② 若双击没反应：检查 Windows 资源管理器是否能解压便携版 zip
     （确认 zip 没损坏，可右键 zip → "7-Zip" → "测试压缩包"）
  ③ 若仍不行：右键 exe →【以管理员身份运行】（应急手段）
  ④ 兜底：Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 →
     添加排除 → 文件夹 → 选「点将台-控制端」或「点将台-大屏端」目录
     （Defender 实时防护可能拦了未签名程序的自解压/提权）
  ⑤ 还不行：启动 → 设置 → 应用 → 已安装的应用 → 找到对应 App → 修复/重置
  ⑥ 终极：用便携版 zip + 启动.bat（在 zip 内）作为 1v1 替代

【为什么会变成 v2.0.0 + UAC 提权（简要）】
  v1.0 → v1.1 → v1.1.1 一直在修「普通权限下双击没反应」：
  v1.1 禁沙箱 → v1.1.1 仍复现 → 排查链覆盖 Defender/ASR/AppLocker/WDAC/事件
  日志/崩溃日志，定位为「中完整性令牌下未签名 Electron 被静默终止」。
  v1.1.2 改用 requireAdministrator 清单（注入 electron.exe 母版），双击
  弹 UAC 提权到高完整性令牌，从根上解决。v2.0.0 在此基础上把单 exe 双模式
  拆为控制端/大屏端两个独立 App，让教室电脑与教师电脑各装各的，配置/部署
  更简单。

【v1.x → v2.0.0 升级建议】
  · 教室大屏电脑：卸载旧版「点将台桌面版」（v1.x）→ 装「点将台-大屏端」
  · 教师电脑：卸载旧版 → 装「点将台-控制端」
  · 云端无需任何操作（worker.js 协议未变，浏览器/桌面端都能直接连）
  · 旧版 v1.x 仍可继续用，与新版并行不冲突（不同 appId/productName，
    注册表 Run 项、托盘互不影响）

【更多】
  · 仓库与发布：github.com/qitian2011/dianjiangtai/releases
  · 下载入口：qitian.dpdns.org/download（4 卡片：控制端单文件/便携 + 大屏端单文件/便携 + 使用说明）
  · 自启动：控制端设置页可设开机自启（HKCU\Run 注册项）

  · 卸载：直接删除程序目录 + 注册表 HKCU\Run 下「点将台-控制端」项即可
