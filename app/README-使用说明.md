# 课堂互动大屏系统 · 使用说明

> 电教委中立立项 · 零依赖离线版 ｜ 需求文档见上级目录 00/01/02

## 30 秒上手

1. 教室一体机双击 **`启动.bat`** → 自动打开大屏页（浏览器按 F11 全屏）
2. 教师手机连**教室同一 WiFi**，浏览器打开大屏页底部黄色地址（`http://一体机IP:8080/ctrl.html`），建议存到桌面
3. 开用：点名页点「随机点名」→ 大屏动画定格 → 「请回答」计时 → 「答对/答错/未答」
4. 「传呼」页：选学生 → 选去处 → 发送 → 大屏弹卡

## 日常操作

| 想做什么 | 在哪做 |
|---|---|
| 导入全班名单 | 控制端 → 名单 → 粘贴导入（一行一名：姓名,学号,组别,权重；Excel 复制即可） |
| 换班级 | 控制端左上角下拉（同房间所有端同步切换） |
| 多教室/多端联动 | URL 加 `?room=教室号`（如 `?room=101`）：同号的两端联动、异号互不影响 |
| 某学生少被点到 | 名单 → 改小权重（默认1，0.5=一半概率） |
| 点过的不再重复 | 勾选「不复读机」（默认开） |
| 语音播报 | 设置页 → 大屏提示方式：仅提示音 / 仅AI播报 / 都要（AI用系统离线中文语音喊出学生姓名） |
| 学生请假 | 点名页 → 今日请假 → 编辑，勾选即当日跳过，次日自动失效 |
| 手机连控制端 | 大屏待机页直接扫码（不用敲网址） |
| 怕打扰考试 | 勾选「考试模式」（大屏只显示角落小字，无声音） |
| 喊错人 | 传呼卡片上点「❌ 撤回」 |

## 手机怎么连一体机（网线直连/无WiFi/无蓝牙场景）

一体机插网线、手机没有可连的 WiFi 时，用下面两种方式之一，**都不用动网线、不耗流量**（只走局域网）：

| 方式 | 操作 | 适用 |
|---|---|---|
| A. 手机开热点（推荐） | 手机开热点（不开流量也行）→ 一体机如果带无线网卡就连上该热点 → 大屏待机页地址列表会出现 192.168.43.x 开头的新地址 → 手机浏览器打开 | 一体机有 WiFi 功能 |
| B. USB 数据线网络共享（无WiFi必选） | 手机用数据线插一体机 → 手机设置里开「USB 网络共享」→ 电脑出现新网卡 → 大屏地址列表出现 192.168.42.x（安卓）或 172.20.10.x（iPhone）开头的新地址 → 手机浏览器打开它 | 任何一体机，一根数据线搞定 |
| C. 完全免网络（降级） | 不用手机，教师直接在大屏上触屏/鼠标操作（或接个无线翻页笔当按键） | 以上都不行时 |

> 改造说明：服务现在会**自动列出所有网卡的候选地址**——大屏待机页底部和启动窗口都会实时显示，插上 USB 或连上热点后地址自动多一行，教师试哪个通就用哪个。

## 技术要点（给维护者）

- **零依赖**：`server.js` 仅用 Node 内置模块（http/SSE），无需 `npm install`，U盘拷贝整个 `app` 文件夹即可部署
- **实时通道**：SSE 下行（服务端→页面）+ POST 上行（控制端→服务端），浏览器断线自动重连
- **数据**：全部在 `roster.json`，名单/统计自动保存；删掉它即恢复出厂示例
- **改端口**：`启动.bat` 里加一行 `set PORT=9090`
- **大屏 URL 提示**：待机页底部显示教师端完整地址；一体机 IP 变化时重启服务即可刷新
- 实现与需求文档的偏差：未用 Socket.IO（需联网装包），改用等价的 SSE 零依赖方案，指标不变（局域网延迟 <200ms）

## 文件结构

```
app/
├── 启动.bat            ← 一键启动（开服务+开大屏页）
├── server.js           ← 服务端（静态页 + SSE + 指令处理 + 名单落盘）
├── roster.json         ← 名单与统计数据
└── public/
    ├── screen.html/js  ← 大屏展示端（动画/倒计时/传呼卡）
    ├── ctrl.html/js    ← 教师控制端（点名/传呼/名单/设置）
    └── style.css       ← 公共样式
```
