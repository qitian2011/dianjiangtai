# Tailscale 远程连接指南
> 用途：在家 / 办公室远程管理教室一体机上的课堂互动大屏（名单管理、偶尔遥控点名）
> 原理：把「一体机」和「手机」组进同一个虚拟局域网，任何网络（流量/异地WiFi）下手机都能直连一体机，加密且免费。
> 适用版本：Windows 一体机（Win10/11）+ Android/iOS 手机

---

## 一、一体机上安装 Tailscale（只需做一次）

**方式 A（推荐）：命令行安装**
1. 在教室一体机上打开 PowerShell（或 CMD），输入：
   ```
   winget install Tailscale.Tailscale
   ```
2. 弹 UAC 窗口点「是」，等待安装完成

**方式 B：手动下载**
1. 浏览器打开 `https://tailscale.com/download/windows` 下载安装包
2. 双击安装，一路默认，最后点「完成」

## 二、一体机登录 Tailscale

1. 屏幕右下角**系统托盘**找到 Tailscale 图标（像个小蜗牛/双箭头）
2. 点击图标 → **Log in / 登录**
3. 浏览器会打开登录页 → 用 **GitHub 账号**登录（你的 qitian2011）→ 授权
4. 登录成功后退回，托盘图标变绿/实心

## 三、查一体机的虚拟 IP（关键数字）

在 PowerShell 里输入：
```
tailscale ip -4
```
会输出类似 `100.101.102.103` 的地址，**记下来**（这就是一体机在任何网络下的固定地址）。
（也可以在托盘图标 → Copy Tailscale IPv4 直接复制）

## 四、手机安装并登录

1. 手机应用商店搜 **Tailscale**（安卓 Google Play / 应用宝；iPhone App Store）安装
2. 打开 App → 用**同一个 GitHub 账号**登录（必须和一休机同一个账号，否则不同网）
3. 登录后 App 里会看到「一体机」这个设备（默认名是电脑名）

## 五、验证与日常使用

1. **手机验证连通**：手机浏览器打开
   ```
   http://100.101.102.103:8080/ctrl.html
   ```
   （把 IP 换成第三步记下的真实地址）→ 能看到控制端页面即成功

2. **远程管理名单**：登录控制端 → 「名单」页 → 增删学生 / 导入 / 改权重 / 建组，改完自动写回一体机上的 roster.json，教室大屏下次点名直接生效

3. **偶尔遥控点名**：人在外地也可以点「随机点名」，大屏（只要一体机开着）会同步播放滚动动画——延迟视网络几十到几百毫秒，能接受

4. **手机快捷方式**：手机浏览器里把控制页「添加到主屏幕」，以后一键打开

## 六、常见问题

| 问题 | 解决 |
|---|---|
| 手机上打不开 | 1) 确认一体机**开机且连网**（Tailscale 服务自启，但电脑得开着）2) 确认手机和一休机登录的是**同一个账号** 3) 一体机托盘图标应显示绿色/已连接 |
| 一体机重启后失联 | 正常现象，Tailscale 开机自启，等 30 秒再试；若没自启：开始菜单搜 Tailscale 手动打开 |
| 手机和一体机不同账号 | 必须同账号，或用 Tailscale admin 控制台邀请（https://login.tailscale.com/admin/machines） |
| 提示端口被拦 | Tailscale 装好后会自动放行虚拟网卡流量，一般无需处理；万一不行，在一体机上运行一次 `app\放行防火墙.bat`（右键管理员） |
| 怎么确认一体机在线 | 手机 App 里看设备状态，或一体机命令行 `tailscale status` |

## 七、安全提示

- Tailscale 默认：**你的账号下所有设备之间互相可达**。自己用没问题；如果以后要共享给同事，在 admin 控制台（https://login.tailscale.com）里把机器加入"共享"或只读 ACL，别裸开。
- 名单数据只在一体机本地，公网上传的是加密流量，没有第三方能看到名单内容。

## 八、完全不用网络时的兜底（复习）

Tailscale 依赖公网，如果哪天学校把外网也断了：
- 一体机**触屏/鼠标**直接操作控制页（`http://localhost:8080/ctrl.html`）——0 网络需求
- 或手机热点 / USB 共享（临时局域网）
三种方式并存，哪个能用用哪个。
